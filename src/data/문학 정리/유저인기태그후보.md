# 유저 인기 태그 후보 목록 (유저인기태그후보.md)

개별 문학 상세 팝업의 "유저 인기 태그" 섹션에서 투표 후보로 뜨는 태그 목록입니다. 공식 태그(AI가 분류하는 기존 장르 태그)는 그대로 유지되고, 이 목록은 그 위에 별도로 얹는 유저 투표 레이어입니다.

자유 제안이 없는 구조라, 아래 "## 후보 목록" 밑에 `-`로 적은 것만 투표 후보가 됩니다(그 위 설명 문단은 파싱 대상이 아닙니다). `3_build_data.py`가 이 목록을 읽어 `pageData/UserTagCatalog.json`을 만듭니다. 여기 없는 이름을 추가하면 `src/js/tagConfig.js`의 `TAG_COLORS`/`TAG_EMOJI`에 없어서 기본 회색으로 나오니, 새 이름을 추가할 땐 그쪽에도 색 한 줄을 같이 넣어주세요.

## 후보 목록

- 일상
- 로맨스
- 피폐
- 슬픔
- 감동
- 코미디
- 후방주의
- 글카스
- 로카

`분류 안함`/`❌ 분류 안함`(운영자 전용 수동 검토 표식, ignoreID.md 참고)과 `이모티콘`은 의도적으로 후보에서 뺐습니다.
