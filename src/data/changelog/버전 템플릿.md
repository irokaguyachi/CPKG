# v0.1 - 2026-08-29 - PWA 업데이트

## 신규 기능

- **앱처럼 설치하기**: 이제 이 사이트를 스마트폰 홈 화면이나 PC 바탕화면에 아이콘으로 추가할 수 있어요. 설치하면 주소창 없이 앱처럼 바로 열립니다.
- **클라우드 동기화 방향 선택**: 동기화 버튼을 누르면 "이 기기 내용을 서버에 저장하기"와 "서버에 있던 내용을 이 기기로 불러오기" 중 원하는 쪽을 직접 고를 수 있습니다.

## 버그 수정

- 모바일 화면에서 로딩 중 뜨는 팁 문구가 화면 밖으로 삐져나오던 문제를 고쳤습니다.
- 모바일에서 "개인 코드 관리"나 "동기화" 팝업이 화면 아래로 잘려서 안 보이던 문제를 고쳤습니다.

## 문학 정리

- "카구야 오배송, 수취인 아즈마 미오" 시리즈에 잘못 섞여 있던 추가편과 IF 놓친 뒤(13화)를, 실제 이야기가 이어지는 "또 다른 카구야와 조우" 시리즈로 옮겼습니다.
- 일부 태그가 맞지 않던 문학을 수정했습니다.

## 기타 수정

- 사이트 주소가 기존 [ckpg.cloud](http://ckpg.cloud) 에서 [**cpkg.cloud](http://cpkg.cloud)** 로 변경되었습니다.
- 사이드바에 존재하는 버전을 누르면 어느 시점에 해당 사이트가 업데이트 되었는지 확인이 가능하게 되었습니다.
