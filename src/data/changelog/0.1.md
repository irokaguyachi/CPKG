# 0.1 - 2026-08-29 - 설치해서 쓸 수 있게 됐어요

## 새로 생긴 기능

- **앱처럼 설치하기**: 이제 이 사이트를 스마트폰 홈 화면이나 PC 바탕화면에 아이콘으로 추가할 수 있어요. 설치하면 주소창 없이 앱처럼 바로 열립니다.
- **로그인 자동완성**: 개인 코드를 입력할 때 브라우저의 비밀번호 관리자가 코드를 기억해 뒀다가 다음부터 자동으로 채워줘요.
- **클라우드 동기화 방향 선택**: 동기화 버튼을 누르면 "이 기기 내용을 서버에 저장하기"와 "서버에 있던 내용을 이 기기로 불러오기" 중 원하는 쪽을 직접 고를 수 있어요.
- **공지사항 통합**: 예전 업데이트 로그 페이지와 공지사항 페이지를 하나로 합쳤어요. 이벤트 공지에는 진행 상태(진행중 / 예정 / 종료)도 함께 표시돼요.

## 고친 문제들

- 모바일 화면에서 로딩 중 뜨는 팁 문구가 화면 밖으로 삐져나오던 문제를 고쳤어요.
- 모바일에서 "개인 코드 관리"나 "동기화" 팝업이 화면 아래로 잘려서 안 보이던 문제를 고쳤어요.
- 상세 이미지가 예전보다 더 빠르게 뜨도록 로딩 방식을 손봤고, 실수로 중복 등록돼 있던 이미지들을 정리했어요.

## 문학 정리

- "카구야 오배송, 수취인 아즈마 미오" 시리즈에 잘못 섞여 있던 추가편과 IF 놓친 뒤(13화)를, 실제 이야기가 이어지는 "또 다른 카구야와 조우" 시리즈로 옮겼어요.

## 그 밖에

- 사이트 주소가 cpkg.cloud로 바뀌었어요.
- 페이지 주소가 더 짧아졌어요 (예: /page/novelPage.html → /novel).
- 야치요 이벤트 이미지에 원작자 출처 표기를 추가했어요.
