# v0.1 - 2026-08-29 - PWA 업데이트

## 신규 기능

- 사이트를 앱처럼 설치할 수 있게 되었습니다. (스마트폰 홈 화면, PC 바탕화면)
- 클라우드 동기화 시 방향을 직접 선택할 수 있게 되었습니다. (서버에 저장하기 / 서버에서 불러오기)

## 버그 수정

- 모바일에서 로딩 팁 문구가 화면 밖으로 나가는 문제가 수정되었습니다.
- 모바일에서 개인 코드 관리, 동기화 팝업이 아래로 잘리는 문제가 수정되었습니다.

## 문학 정리

- "카구야 오배송, 수취인 아즈마 미오" 시리즈에 섞여 있던 추가편과 IF 놓친 뒤(13화)를 "또 다른 카구야와 조우" 시리즈로 옮겼습니다.
- 일부 맞지 않는 태그를 수정했습니다.

## 기타 수정

- 사이트 주소가 ckpg.cloud 에서 [cpkg.cloud](https://cpkg.cloud) 로 변경되었습니다.
- 사이드바의 버전을 누르면 사이트가 언제 업데이트되었는지 확인할 수 있습니다.
