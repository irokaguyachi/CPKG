# v1.0 - 2026-10-03 - UI 전면 개편 업데이트

이번 업데이트는 사이트 자체를 전면 개편한 첫 대형 업데이트입니다! 모두 재미있게 즐겨주세요 :)

## 신규 기능

- 화면 위쪽에 통합 검색창이 추가되었습니다. 문학, 번역, 시리즈, 명예관, 공식 작품을 제목으로 한 번에 찾을 수 있고, 결과를 누르면 작품 상세 창이 바로 열립니다.
- 통합 검색은 초성(예: ㅇㄹㅎ)이나 게시글 번호로도 찾을 수 있습니다. 키보드에서 / 키를 누르면 어느 페이지에서든 검색창으로 바로 이동합니다.
- 헤더 오른쪽 끝에 프로필 버튼이 추가되었습니다. 누르면 로그인, 동기화(서버에 저장·불러오기), 개인 코드 보기, 로그아웃을 한곳에서 할 수 있습니다.
- 로그인한 상태에서는 프로필 버튼에 붙은 작은 점의 색으로 동기화 상태를 확인할 수 있습니다.
- 헤더에서 라이트 모드와 다크 모드를 바로 바꿀 수 있습니다.
- 사이트 언어 설정이 추가되었습니다. 설정의 일반 탭에서 한국어, English, 日本語 중 하나를 고를 수 있습니다.
- 언어 설정은 메뉴, 버튼, 안내 문구 같은 사이트 화면에만 적용됩니다. 문학·번역의 제목과 본문, 태그, 공지사항 본문은 원문 그대로 표시됩니다.
- 설정에 보기 탭이 추가되었습니다. 목록을 그리드와 리스트 중 어떤 방식으로 볼지, 그리드 카드를 어떤 모양으로 볼지 예시 그림을 보면서 고를 수 있습니다.
- 보기 설정은 고르는 즉시 새로고침 없이 목록에 적용되고, 문학·번역, 시리즈, 명예관, 공식 목록에 모두 똑같이 적용됩니다.
- 메인 화면에 공지사항 위젯이 추가되었습니다. 공지사항과 업데이트 로그를 최신순으로 한곳에서 볼 수 있고, 화살표 버튼으로 이전 글을 넘겨 볼 수 있습니다.
- 공지사항 위젯에서 글을 누르면 공지사항 페이지에서 그 글이 바로 열립니다.
- 공지사항 위젯 옆에 최신 업데이트 카드가 추가되었습니다. 가장 최근 업데이트의 주요 내용을 확인하고 바로 이동할 수 있습니다.

## 디자인 변경

- 오른쪽 위 메뉴 버튼을 눌러 열던 사이드바가 사라지고, 모든 페이지 위쪽에 메뉴가 항상 보이는 두 줄짜리 헤더로 바뀌었습니다. 지금 보고 있는 페이지의 메뉴에는 밑줄이 표시됩니다.
- 헤더 메뉴에 마우스를 올리면 페이지마다 정해진 색으로 글자와 밑줄이 은은하게 빛납니다.
- 설정 버튼은 메뉴 줄의 오른쪽 끝으로 옮겨졌습니다.
- 문학 탭과 번역 탭이 '문학·번역' 탭 하나로 합쳐졌습니다. 페이지 위쪽의 [문학 | 번역] 버튼으로 목록을 바꿔 볼 수 있습니다.
- 번역 목록의 주의 안내와, 아래로 스크롤하기 전까지 목록을 흐리게 가려 두는 방식은 그대로 유지됩니다.
- 메인 화면의 진행 중인 대회 카드와 신규 기능 알림 카드가 큰 가로 배너로 바뀌었습니다. 대회 배너에는 마감까지 남은 날과 대회 기간이 함께 표시됩니다.
- 오디오 노벨 화면의 화 제목이 헤더 가운데에서 본문 맨 위로 옮겨졌습니다.
- 그리드 카드 모양이 세 가지 더 생겼습니다. 기존 모양(기본) 외에 표지형, 매거진형, 컴팩트 중에서 고를 수 있습니다.
- 표지형은 책 표지처럼 세로로 긴 카드에 그림을 꽉 채우고 그 위에 제목을 올립니다. 정사각형 그림이 거의 잘리지 않고, 한 화면에 더 많은 작품이 들어갑니다.
- 매거진형은 정사각형 그림 아래에 태그 색 점, 두 줄 제목, 작가와 글자 수를 차분하게 보여 줍니다.
- 컴팩트는 작은 그림 옆에 제목을 두는 타일 모양으로, 제목 위주로 빠르게 훑어볼 때 가장 많은 작품을 볼 수 있습니다.
- 리스트 보기가 게시판형으로 바뀌었습니다. 그림, 제목과 태그, 작가, 글자 수가 한 줄에 정리되어 한 화면에 훨씬 많은 작품이 보입니다.
- 리스트에서는 북마크·끌올 버튼이 그림을 가리지 않도록 줄 끝으로 옮겨졌습니다.
- 이미지가 없는 문학은 회색 칸 대신 책 표지처럼 표시됩니다. 대표 태그의 색과 이모지, 제목, 작가 이름이 들어가고, 마우스를 올리면 은은한 빛이 흐릅니다.
- 작가 이름은 앞 두 글자만 보이고 나머지는 ***로 가려집니다. (모든 카드 모양과 리스트, 문학·번역 룰렛 포함)
- 이미지를 불러오는 동안 이미지 자리에 은은한 빛이 천천히 움직이는 로딩 효과가 추가되었습니다.
- 이미지를 다 불러오면 갑자기 튀어나오지 않고, 로딩 효과가 걷히면서 서서히 나타납니다.

## 모바일 개편

- 휴대폰 화면에서는 위쪽 메뉴 줄 대신 화면 아래에 홈, 메뉴, 프로필 탭이 생겼습니다.
- 메뉴 탭을 누르면 페이지 버튼이 아래에서 올라옵니다. 맨 위에 큰 문학·번역 버튼이 있고, 그 아래에 나머지 페이지가 두 줄로, 맨 아래에 공지사항이 놓입니다.
- 문학·번역 버튼 안에는 움직이는 그림 효과가 번갈아 나타났다 사라집니다.
- 화면 오른쪽 아래에 떠서 본문을 가리던 북마크·룰렛 버튼은 메뉴 탭 안으로 옮겨졌습니다.
- 프로필 탭을 누르면 계정 메뉴, 화면 테마, 설정을 한곳에서 바꿀 수 있습니다.
- 위쪽의 돋보기 버튼을 누르면 통합 검색창이 펼쳐집니다.
- 버튼이나 카드를 누를 때 그 크기만큼 파랗게 번쩍이던 효과를 없앴습니다.

## 메인 화면 개편

- 오늘의 랜덤 문학 / 번역이 공지사항 위젯과 같은 모양의 카드로 바뀌었습니다. 왼쪽에는 오늘 뽑힌 문학과 번역이, 오른쪽에는 다음 뽑기까지 남은 시간이 크게 표시됩니다.
- 열기 전에는 그림이 흐리게 가려져 있고, '오늘의 글 열기' 버튼이나 글을 누르면 오늘의 글이 공개됩니다.
- 오늘의 글을 연 뒤에는 문학 룰렛으로 더 뽑아 볼 수 있는 버튼이 표시됩니다.
- 끌올 배너가 작품 그림을 크게 깐 카드로 바뀌었습니다. 그림 위에 제목, 태그, 글자 수와 교체까지 남은 시간이 함께 표시됩니다.
- 최신 등록 문학과 최근 등록 번역이 각각 한 장의 카드로 바뀌었습니다. 왼쪽 큰 카드에서 작품을 하나씩 크게 소개하고, 오른쪽 목록에서는 최근 15개를 스크롤해 볼 수 있습니다.
- 큰 카드는 5초마다 목록 순서대로 다음 작품으로 넘어가고, 지금 소개 중인 작품은 오른쪽 목록에서 강조 표시됩니다. 문학과 번역은 같은 순간에 함께 넘어갑니다.
- 카드 위에 마우스를 올리거나 목록을 넘기는 동안에는 잠시 멈춥니다.
- 최근 등록 번역의 주의 안내는 카드 안의 얇은 띠로 바뀌었습니다. 사진을 흐리게 가리는 방식은 그대로 유지됩니다.
- 랜덤 문학, 랜덤 번역, 랜덤 시리즈, 랜덤 명예관이 '랜덤 픽' 카드 하나로 합쳐졌습니다. 네 칸이 번갈아 가며 5초마다 새 작품으로 바뀌고, 마우스를 올린 칸은 바뀌지 않습니다.
