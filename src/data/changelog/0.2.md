# v0.2 - 2026-09-02 - 오디오 노벨 업데이트 (실험)

## 신규 기능

- 오디오 노벨이 추가되었습니다. 문단을 스크롤하면 장면에 맞는 배경음악이 재생되고, 삽화가 있는 장면에서는 그림도 함께 나옵니다.
- 목록에서 🎧 오디오노벨 리본이 붙은 작품이 지원 작품입니다. 상세 목록에서 AUDIO 배지가 붙은 화를 누르면 오디오 노벨로 읽을 수 있습니다.
- 지원 작품: 초 카구야 공주! 소설판 (서장~1장, 2장)

- 새 업데이트나 중요한 소식이 있을 때 메인 화면 상단에 배너가 표시됩니다.
