# v0.3 - 2026-09-05 - 유저 태그 업데이트 (베타)

## 신규 기능

- 유저 인기 태그 투표가 추가되었습니다. 문학 상세보기에서 `+` 버튼을 눌러 원하는 태그에 투표할 수 있습니다. (로그인 필요, 다시 누르면 취소)
- 유저 인기 태그는 기존 공식 태그와 따로 표시됩니다.
- 문학 목록의 태그 필터에서 공식 태그 / 유저 태그를 전환할 수 있습니다.

## 버그 수정

- 상세보기 태그의 `+` 버튼이 밝은 이미지 위에서 잘 안 보이는 문제가 수정되었습니다.
- 다크 모드에서 상세보기 태그가 라이트 모드 색으로 나오는 문제가 수정되었습니다.

## 기타 수정

- 상세보기 태그의 크기와 색을 수정했고, 모바일에서는 라벨과 태그가 한 줄로 보이도록 바꿨습니다.
- 후방주의(성인) 태그가 붙은 문학은 기본적으로 숨겨집니다. (설정 > 일반 > 🔞 후방주의 태그 문학 표시)
