# v0.3 - 2026-09-05 - 유저 태그 업데이트 (베타)

## 신규 기능

- **유저 인기 태그 투표**: 개별 문학 상세보기를 열면 기존처럼 자동으로 붙는 **공식 태그**와는 별도로 **유저 인기 태그** 항목이 새로 생겼어요. `+` 버튼을 누르면 태그 후보 목록이 뜨고, 마음에 드는 태그에 직접 투표할 수 있습니다. 투표하려면 로그인(개인 코드)이 필요하고, 이미 고른 태그는 다시 눌러 취소할 수도 있어요. 공식 태그를 대체하는 게 아니라 그 위에 얹는 기능이라, 기존 문학·새로 올라오는 문학 모두 똑같이 투표할 수 있습니다.
- **문학 목록 필터에서 공식/유저 태그 전환**: 문학 목록 페이지에서 태그 필터를 열면 오른쪽 위에 "공식 태그"/"유저 태그" 버튼이 생겼어요. 눌러서 보기를 바꾸면 카드에 표시되는 태그와 필터 목록이 함께 전환됩니다.

## 버그 수정

- 상세보기 태그 알약의 `+` 더보기 버튼이 밝은 배경 이미지 위에서 거의 안 보이던 문제를 고쳤습니다.
- 상세보기 태그가 다크 모드에서도 라이트 모드 색 그대로 나오던 문제를 고쳐서, 이제 목록 카드와 똑같은 다크 톤으로 보입니다.

## 기타 수정

- 상세보기 태그 알약 크기와 색을 다듬고, 모바일 화면에서는 라벨과 태그가 나란히 한 줄로 보이도록 레이아웃을 정리했습니다.
- 후방주의(성인) 태그가 붙은 문학은 기본값으로 목록과 상세 화면에서 보이지 않도록 했습니다. 보고 싶으시면 설정 > 일반 > 🔞 후방주의 태그 문학 표시를 켜주세요.
