# v0.0 - 2026-08-28 - 사이트를 소개합니다

초카공 갤러리에 오신 걸 환영해요! 어떤 곳인지, 뭘 할 수 있는지 짧게 소개할게요.

## 어떤 사이트인가요?

이 사이트는 디시인사이드 초 카구야 공주 갤러리에 올라온 팬 창작 문학을 한곳에 모아 정리한 **비공식 팬메이드 아카이브**예요. 여기저기 흩어져 있던 글들을 편하게 찾아보고, 태그와 검색으로 원하는 이야기를 빠르게 발견할 수 있도록 만들었습니다.

**이 사이트는 절대로 초! 카구야 공주의 공식이 아니며, 팬이 자발적으로 운영하는 페이지예요.**

## 페이지 소개

- **메인**: 사이트에 들어오면 가장 먼저 보이는 곳이에요. 최근에 새로 등록된 문학을 미리 볼 수 있어요.
- **공식**: 공식/운영진 명의로 올라온 게시물을 모아뒀어요.
- **번역** (준비 중): 다른 언어로 된 작품을 소개하는 공간이 될 예정이에요. 지금은 준비 중이라 잠겨 있어요.
- **문학**: 시리즈로 이어지지 않는 단독 작품들을 모아뒀어요.
- **시리즈**: 여러 화로 이어지는 연재작들을 모아뒀어요.
- **명예관**: 많은 사랑을 받은 우수 작품들을 모아둔 명예의 전당이에요.
- **북마크**: 마음에 드는 글을 담아두는 나만의 보관함이에요. 로그인 없이 이 브라우저에 바로 저장할 수 있고, 개인 코드로 로그인하면 다른 기기에서도 같은 목록을 이어서 볼 수 있어요. 원하면 내 북마크 모음을 다른 사람에게 공개할 수도 있어요.
- **업데이트 로그**: 지금 보고 계신 이 페이지예요. 사이트가 어떻게 바뀌어왔는지 버전별로 확인할 수 있어요.

## 둘러보기 편하게 해주는 기능들

- **검색**: 제목으로 바로 찾을 수 있고, 자음만 입력해도(초성 검색) 찾아져요.
- **태그 필터**: 원하는 태그만 골라서 볼 수 있어요.
- **그리드 / 리스트 보기**: 취향에 맞는 보기 방식으로 전환할 수 있어요.
- **다크 모드**: 화면 밝기를 눈에 맞게 바꿀 수 있어요.
