# v0.4 - 2026-09-14 - 번역 탭 & 끌올 업데이트

## 신규 기능

- **끌올**: 로그인한 계정이 원하는 문학을 사이트 맨 위에 노출시켜 달라고 신청할 수 있는 기능이 생겼어요. 북마크 버튼 옆의 🔥 버튼을 누르면 신청할 수 있고, 순서가 되면 최대 1시간 동안 메인 페이지 맨 위에 노출됩니다. 계정당 10분에 한 번만 신청할 수 있고, 이미 끌올되어 있는 문학은 다시 신청할 수 없어요.
- **번역 탭**: 번역된 문학만 모아보는 탭이 새로 생겼어요. 지금까지 모은 번역 게시물 1,196건을 한 번에 볼 수 있습니다. 이 탭은 공식 태그 대신 유저 인기 태그만 지원하고, 별도 필터링을 거치지 않은 게시물이 섞여 있을 수 있어 열람 시 주의 문구가 함께 표시됩니다.
- **일일 번역**: 이제 랜덤 문학 페이지에서 번역 게시물도 같이 추천합니다!

## 버그 수정

- 오늘의 문학(랜덤 뽑기)이 모든 방문자에게 똑같이 나오던 문제를 고쳤습니다. 이제 방문자마다 다른 글이 나오고, 하루 동안은 고정되며 자정(KST)에 새 글로 넘어갑니다.
