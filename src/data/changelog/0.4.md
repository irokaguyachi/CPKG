# v0.4 - 2026-09-14 - 번역 탭 & 끌올 업데이트

## 신규 기능

- 끌올 기능이 추가되었습니다. 북마크 옆 🔥 버튼으로 신청하면 순서대로 최대 1시간 동안 메인 맨 위에 노출됩니다. (로그인 필요, 계정당 10분에 한 번)
- 이미 끌올된 문학은 다시 신청할 수 없습니다.
- 번역 탭이 추가되었습니다. 지금까지 모은 번역 게시물 1,196건을 볼 수 있습니다.
- 번역 탭은 유저 인기 태그만 지원하며, 필터링되지 않은 게시물이 있을 수 있어 주의 문구가 표시됩니다.
- 랜덤 문학에서 번역 게시물도 함께 추천합니다.

## 버그 수정

- 오늘의 문학이 모든 방문자에게 똑같이 나오던 문제가 수정되었습니다. 이제 방문자마다 다르게 나오고, 자정(KST)에 바뀝니다.

## 문학 정리

- 신규 문학 게시물 23개가 추가되었습니다. (306,763번 ~ 311,288번 구간)
