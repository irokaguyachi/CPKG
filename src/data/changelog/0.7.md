# v0.7 - 2026-10-01 - 헤더 개편 & 문학·번역 통합 업데이트

## 신규 기능

- 화면 위쪽에 통합 검색창이 추가되었습니다. 문학, 번역, 시리즈, 명예관, 공식 작품을 제목으로 한 번에 찾을 수 있고, 결과를 누르면 작품 상세 창이 바로 열립니다.
- 통합 검색은 초성(예: ㅇㄹㅎ)이나 게시글 번호로도 찾을 수 있습니다. 키보드에서 / 키를 누르면 어느 페이지에서든 검색창으로 바로 이동합니다.
- 헤더 오른쪽 끝에 프로필 버튼이 추가되었습니다. 누르면 로그인, 동기화(서버에 저장·불러오기), 개인 코드 보기, 로그아웃을 한곳에서 할 수 있습니다.
- 로그인한 상태에서는 프로필 버튼에 붙은 작은 점의 색으로 동기화 상태를 확인할 수 있습니다.
- 헤더에서 라이트 모드와 다크 모드를 바로 바꿀 수 있습니다.

## 디자인 변경

- 오른쪽 위 메뉴 버튼을 눌러 열던 사이드바가 사라지고, 모든 페이지 위쪽에 메뉴가 항상 보이는 두 줄짜리 헤더로 바뀌었습니다. 지금 보고 있는 페이지의 메뉴에는 밑줄이 표시됩니다.
- 설정 버튼은 메뉴 줄의 오른쪽 끝으로 옮겨졌습니다.
- 문학 탭과 번역 탭이 '문학·번역' 탭 하나로 합쳐졌습니다. 페이지 위쪽의 [문학 | 번역] 버튼으로 목록을 바꿔 볼 수 있습니다.
- 번역 목록의 주의 안내와, 아래로 스크롤하기 전까지 목록을 흐리게 가려 두는 방식은 그대로 유지됩니다.
- 오디오 노벨 화면의 화 제목이 헤더 가운데에서 본문 맨 위로 옮겨졌습니다.
- 모바일에서는 돋보기 버튼을 누르면 검색창이 펼쳐지고, 메뉴는 옆으로 밀어서 볼 수 있습니다.
