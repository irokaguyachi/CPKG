# v0.5 - 2026-09-27 - 문학·번역 룰렛 & 끌올 개편 업데이트

## 신규 기능

- 문학 룰렛이 추가되었습니다. 룰렛이 공식 태그 하나를 고른 뒤, 그 태그가 붙은 문학 중 한 편을 추천합니다.
- 추천된 문학은 작품 보기로 바로 읽을 수 있고, 같은 태그로 다시 뽑을 수도 있습니다.
- 번역 룰렛(슬롯머신)이 추가되었습니다. 레버를 당기면 전체 번역 1,241건 중 한 편을 추천합니다.
- 번역 룰렛은 필터링되지 않은 게시물이 나올 수 있어 주의 문구가 함께 표시됩니다.
- 두 룰렛은 화면 오른쪽 아래 버튼으로 사용할 수 있습니다. (메인, 공식, 번역, 문학, 시리즈, 명예관, 북마크 페이지)
- 후방주의 태그를 숨겨둔 경우 문학 룰렛에서도 나오지 않습니다.

## 대회 탭

- 사이드바에 대회 탭이 추가되었습니다. 대회별로 기간과 참가작을 모아 볼 수 있습니다. (초음문대, 일문대, 카백대, 카문대)
- 진행 중인 대회에는 마감까지 남은 날이 표시되고, 새로 올라오는 참가작도 자동으로 모입니다.
- 대회 상세 화면에서 개최 글로 바로 이동할 수 있습니다.
- 진행 중인 대회는 메인 화면에도 홍보 카드로 표시됩니다.

## 끌올 변경

- 끌올이 1시간 뒤에 끝나지 않고, 다음 끌올 신청이 들어올 때까지 메인 맨 위에 유지됩니다.
- 다음 신청이 들어오면 현재 끌올된 시간에 따라 교체됩니다. (24시간 이상은 즉시, 6시간 이상은 10분 뒤, 1시간 이상은 1시간 뒤)
- 끌올된 지 1시간이 안 됐다면 1시간을 채운 뒤 1시간 더 유지됩니다. (최소 2시간)
- 교체를 기다리는 중에 6시간이나 24시간을 넘기면 그 기준에 맞춰 더 일찍 교체됩니다.
- 교체 시점이 정해지면 메인 끌올 배너에 교체까지 남은 시간이 표시됩니다.

## 버그 수정

- 모바일 상세보기에서 태그가 많을 때 제목이 잘리는 문제가 수정되었습니다. 이제 태그가 많아지면 위쪽 이미지 영역이 그만큼 늘어납니다.
- 메인 화면 위쪽 위젯의 순서가 불러오는 속도에 따라 바뀌던 문제가 수정되었습니다. 이제 항상 신규 알림, 끌올, 대회, 오늘의 문학·번역 순으로 표시됩니다.

## 문학/번역 정리

- 신규 번역 45개가 추가되었습니다. (309,263번 ~ 321,522번)
- 공식 탭에 따로 있던 '초 카구야 밥 1화' 번역을 '초 카구야 밥!' 시리즈로 합쳤습니다. 이제 상세 화면에서 0화와 1화를 이어서 볼 수 있습니다.

## 기타 수정

- 북마크가 사이드바에서 화면 오른쪽 아래 버튼(룰렛 버튼 위)으로 옮겨졌습니다.
- 브라우저 탭 제목이 '초카공 문학&번역 • 페이지 이름' 형식으로 바뀌었습니다.
- 사이드바 메뉴의 마우스 오버 색상이 모든 항목에 이어지도록 수정했습니다.
