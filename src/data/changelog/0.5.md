# v0.5 - 2026-09-27 - 문학·번역 룰렛 업데이트

## 신규 기능

- **문학 룰렛**: 화면 오른쪽 아래에 빙글빙글 도는 **문학 룰렛** 버튼이 생겼어요. 누르면 룰렛 창이 열리고, 가운데 SPIN 버튼을 누르면 룰렛이 문학 태그 하나를 고른 뒤 그 태그가 붙은 문학 중 한 편을 뽑아 드립니다. 마음에 들면 **작품 보기**로 바로 읽으러 갈 수 있고, **같은 태그로 다시 뽑기**를 누르면 같은 태그 안에서 다른 문학을 다시 뽑아요. 설정에서 후방주의 태그 문학을 숨겨 두었다면 룰렛에서도 나오지 않습니다.
- **번역 룰렛**: 문학 룰렛 바로 위에 **번역 룰렛** 버튼도 생겼어요. 번역은 태그가 없어서 칸이 하나뿐인 슬롯머신으로 만들었고, 레버를 당기면 지금까지 모은 번역 1,241건 중 한 편이 바로 나옵니다. 번역 탭과 마찬가지로 별도 필터링을 거치지 않은 게시물이 나올 수 있어서 주의 문구가 함께 표시돼요.
- 두 룰렛 버튼은 메인, 공식, 번역, 문학, 시리즈, 명예관, 북마크 페이지에서 쓸 수 있어요. 버튼에 마우스를 올리면 룰렛이 더 빠르게 돌고, 번역 룰렛은 레버가 내려갑니다.

## 버그 수정

- 모바일에서 상세보기를 열었을 때 공식 태그와 유저 인기 태그가 함께 표시되면 위쪽 제목이 잘려 보이던 문제를 고쳤습니다. 이제 태그가 많아지면 위쪽 이미지 영역이 그만큼 늘어나서 제목과 태그가 모두 보여요.

## 문학/번역 정리

- 신규 번역 게시물 45개가 추가되었습니다. (309,263번 ~ 321,522번 구간)
- 공식 탭에서 따로 떨어져 있던 **초 카구야 밥 1화** 번역을 **초 카구야 밥!** 시리즈의 1화로 합쳤어요. 이제 상세 화면에서 0화와 1화를 이어서 볼 수 있습니다.

## 기타 수정

- 사이드바 메뉴에 마우스를 올렸을 때 나오는 무지개 색을 다듬었어요. 이제 메인부터 북마크까지 공지사항을 포함한 8개 항목에 위에서부터 차례로 색이 이어집니다.
