# 메모장 사전 정리 규칙 (rules/notepad-prep.md)

문학 데이터를 사이트용으로 빌드 및 정리하기 전, 반드시 메모장(텍스트/마크다운) 형식으로 1차 정리를 완료해야 합니다.

⚠️ **필수 사전 선행 절차**:
- 메모장에 태그를 지정하기 전, **AI 에이전트는 반드시 `rules/tag.md` 파일의 설명을 참조/확인**한 후 분류해야 합니다.

1. **파일 단위 분할 및 게시글 ID 범위 매핑**:
   - 게시글 ID 범위별 파일 분할 기준은 `rules/crawling.md` 1번 항목의 표를 **단일 기준**으로 따릅니다 (여기서 별도로 중복 관리하지 않음).



2. **필수 정리 항목 (5가지 + 사진 정보)**:
   - **게시물 이름** (제목)
   - **게시물 링크** (URL)
   - **작성자**: 닉네임 및 고닉/IP 정보 (예: `코유키1357(merry8851)`, `ㅇㅇ(175.116)`)
   - **태그**: `rules/tag.md` 지침에 근거하여 부여된 태그
   - **글자 수**: 본문 전체 텍스트 글자 수 (예: `12,314자`, `874자`)
   - **사진 정보**: 첨부된 사진 파일명 (`사진/차수/게시물번호_사진순번.확장자`)
     - 예: `사진/1/1024_1.jpg`, `사진/2/10500_1.png`



3. **시리즈 문학 독립 관리 (`시리즈/` 폴더)**:
   - **독립 폴더 활용**: 연재 회차가 `크롤링/1.md`, `크롤링/15.md` 등 서로 다른 게시글 ID 분할 파일로 흩어지는 것을 방지하기 위해 **`시리즈/` 전용 폴더**를 생성하여 별도로 모아서 관리합니다.
   - **파일 생성 및 정리 규칙**:
     - 시리즈별 독립 파일(예: `시리즈/나에게 너무 적극적인 전학생!.md`)을 생성합니다.
     - 각 파일 내부에는 `시리즈 1: [게시글]`, `시리즈 2: [게시글]` 순서대로 연속 정리하며, 새로운 회차가 올라오면 해당 시리즈 파일 하단에 덧붙여 통합 관리합니다.
   - **판별 기준**:
     1. **디시인사이드 자체 시리즈 기능 (`series_no`) [1순위]**: 본문의 디시 공식 시리즈 ID/시리즈명을 수집하여 100% 정확히 동일 시리즈 파일로 자동 묶음.
     2. **제목 패턴 기반 보완 [2순위]**: 디시 시리즈 미설정 글은 제목 패턴(-1-, -2-, 1/n 등)을 검증하여 보완 판단.
