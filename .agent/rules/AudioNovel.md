# 오디오 노벨 (Audio Novel) 기능 기획 (2026-08-30)

> 상태: **계획 단계 — 아직 아무 코드도 바꾸지 않았습니다.**
> 방향을 확정하기 위한 정리 문서입니다.

## 배경

> "네이버 웹툰 보면 가끔씩 음악이 같이 수록이 되어있는게 있잖아? 그것처럼 소설을 볼때 음악을 같이 보면서 할수 있게 하면 좋겠어"

처음에는 "카드를 열거나 원문 링크를 누르는 순간 이 사이트 탭에서 배경음악이 흐르기 시작하는" 방향으로 검토했으나, 방향을 다시 잡았습니다. **오디오 노벨로 지정된 게시물은 사이트 안에서 직접 읽는 전용 페이지를 가지며, 그 본문 자체를 사용자가 직접 만든 태그 문법으로 작성해 장면마다 음악과 이미지를 심습니다.**

## 핵심 구조: 원문 링크 + 자체 제작 본문

오디오 노벨 리더 페이지는 두 부분으로 구성됩니다.

1. **맨 위**: 디시인사이드 원문 게시글 링크 (출처 표시, 지금처럼 새 탭으로 열림)
2. **그 아래**: 사용자가 직접 작성한 마크다운 형식 파일을 사이트 안에서 그대로 렌더링한 본문. 일반 텍스트 줄글 사이에 아래 태그를 섞어 씀

이 본문 파일은 크롤링 원본(`src/data/문학 정리/*.md`)을 그대로 쓰는 게 아니라, 오디오 노벨 연출을 위해 **새로 직접 작성하는 별도 파일**입니다.

## 실제 작업 폴더 구조

기획과 별개로 사용자가 이미 아래 구조로 실제 작업을 시작했습니다. 계획도 이 구조를 기준으로 삼습니다.

```
src/audioNovel/
├── novelData/
│   ├── backup/                 # 크롤링 원본 백업 (장별 txt + 이미지, 손대지 않음)
│   │   └── 서장/, 제 2장/, ...
│   ├── ㅇㅇ/                    # 태그 없는 순수 초안 (장별로 세분화된 .md)
│   │   └── 1장.md, 2장_1.md, 2장_2.md, ...
│   └── official/                # 태그를 붙인 최종 편집본 — 리더 페이지가 실제로 읽는 파일
│       └── 1장.md, ...
└── asset/
    ├── img/                      # 오디오 노벨 전용 이미지
    └── sound/
        └── music/
            ├── (공용 트랙들).mp3
            └── official/novel/
                ├── OPENING ACT@TSUKUYOMI.mp3
                ├── Iroha Sakayori.mp3
                ├── Remember.mp3
                └── AudioData.json   # 이 폴더 트랙들의 작곡가·곡명 메타데이터
```

`asset` 쪽은 이후 별도 클라우드 스토리지에 올릴 예정이라, 리더 페이지에서 참조하는 음원·이미지 경로는 최종적으로 그 클라우드 URL로 바뀔 수 있습니다 (지금은 로컬 상대경로 기준으로 프로토타입 진행).

## 태그 문법

| 태그 | 형태 | 동작 |
|---|---|---|
| 사운드 구간 | `<sound="music/official/novel/fullmoon">...한 문단...</sound>` | 여는 태그부터 해당 곡 재생을 시작하고, 닫는 태그에서 그 문단이 끝남. **문단마다 여닫는 것이 기본 단위** |
| 이미지 삽입 | `<img="...">` | 닫는 태그 없이 그 위치에 이미지 한 장을 삽입 (self-closing) |
| 효과음 | `<sfx="이로하_리멤버">` | 닫는 태그 없는 점(point) 트리거 (self-closing). 배경음악(`sound`)과 독립적으로 겹쳐서 재생되며, 그 지점을 읽고 지나치는 순간 **딱 한 번만** 재생된다(loop 없음). 값은 `src/audioNovel/asset/sound/sfx/official/` 기준 확장자 없는 파일명 |

예시 (문단마다 여닫되, 같은 곡이 이어지면 값이 반복됨):

```
<img="공식/소설판/01_표지.jpg">

<sound="music/official/novel/OPENING ACT@TSUKUYOMI">카구야는 달을 올려다보았다.</sound>

<sound="music/official/novel/OPENING ACT@TSUKUYOMI">"오늘 밤은 유난히 밝네."</sound>

<sound="music/official/novel/battle">그 순간, 검은 그림자가 덮쳐왔다.</sound>
```

`sound`의 값(`music/official/novel/fullmoon`)은 확장자 없는 경로이며, 실제 파일은 `src/audioNovel/asset/sound/music/official/novel/fullmoon.mp3` 식으로 매핑됩니다.

### 중요: 인접한 같은 곡 문단은 하나의 재생 구간으로 합침

닫는 태그를 문단마다 넣기 때문에, 같은 곡이 여러 문단에 걸쳐 이어지는 경우가 흔합니다. 이때 문단 경계마다 곡을 처음부터 재시작하면 곡이 계속 끊기므로, **파서 단계에서 `sound` 값이 연속으로 동일한 문단들을 하나의 재생 구간으로 병합**합니다. 곡이 실제로 바뀔 때만 새로 재생을 시작합니다.

### AudioData.json 스키마

오디오 노벨 하단에 작게 들어갈 미니 플레이어에 표시할 **작곡가 / 곡명** 메타데이터를 담습니다. 트랙이 있는 폴더마다 그 폴더의 트랙들을 키로 갖는 파일입니다.

```json
{
  "OPENING ACT@TSUKUYOMI": {
    "title": "OPENING ACT@TSUKUYOMI",
    "composer": "작곡가명"
  },
  "Iroha Sakayori": {
    "title": "Iroha Sakayori",
    "composer": "작곡가명"
  }
}
```

## 1차 적용 범위: 공식(Official) 섹션

전체 문학(2,000여 편)이 아니라 **공식 섹션**부터 적용합니다.

- 시리즈 4개, 게시물 20여 개뿐이라 전량을 직접 새로 작성하는 것이 현실적인 규모
- 세계관 안에 이미 "가이드북 3 (뮤직)"이라는 공식 음악 개념이 존재 — 결이 맞음
- 시리즈/명예관/문학 등 다른 섹션으로의 확대는 지금 범위 밖. 공식 섹션에서 검증 후 재논의

## 확정된 사항

| 항목 | 결정 |
|---|---|
| 읽는 방식 | 새 탭으로 원문 링크만 여는 게 아니라, **사이트 안 전용 리더 페이지**에서 직접 작성한 본문을 읽음. 원문 링크는 맨 위에 출처로 남김 |
| 본문 작성 | **사용자가 직접** `<sound>`/`<img>` 태그를 섞어 새로 작성 (크롤링 원본 자동 변환 아님) |
| 음악 매칭 단위 | 화(episode) 전체가 아니라 **`<sound>` 구간 단위** — 한 화 안에서도 장면마다 곡이 바뀔 수 있음 |
| 음원 소스 | **사용자가 직접 파일을 준비**해서 assets 폴더에 넣는 방식. 무료 음원 추천이나 자동 소싱은 하지 않음 |
| 재생 트리거 | **스크롤로 `<sound>` 구간이 화면에 들어오면 자동 재생** (`IntersectionObserver` 기반) |

## 구현 조각 (예상)

1. **파서**: `<sound="...">...</sound>` / `<img="...">` 태그와 일반 줄글이 섞인 텍스트를 문단 단위 세그먼트 배열로 분해. 인접한 문단의 `sound` 값이 같으면 하나의 구간으로 병합
2. **렌더러**: 병합된 세그먼트를 DOM으로 그리며, 각 사운드 구간을 하나의 블록(`<section data-sound="...">`)으로 감싸 재생 트리거를 걸 수 있게 함
3. **재생 트리거**: 구간이 뷰포트에 들어오면 재생 시작, 빠져나가면 정지 (`IntersectionObserver`)
4. **미니 플레이어**: 리더 페이지 하단에 작게 고정. 현재 재생 중인 곡을 `AudioData.json`에서 찾아 곡명·작곡가 표시 + 재생/일시정지·음소거
5. **리더 페이지**: 신규 `src/page/audioNovelReaderPage.html` + `src/js/audioNovelReaderPage.js` — 상단 원문 링크, 하단 렌더링된 본문 + 미니 플레이어
6. **본문 원본 파일**: `src/audioNovel/novelData/official/<장>.md` (이미 존재하는 실제 작업 폴더)
7. **오디오·이미지 에셋**: `src/audioNovel/asset/` 밑 (이미 존재). `CLAUDE.md`의 커스텀 에셋 보호 수칙에 `src/audioNovel/asset/`도 포함시켜야 함
8. **연결 지점**: `Official.json`의 해당 게시물 항목에 리더 페이지로 연결되는 필드(예: `"reader": "1장"`)를 추가해, 오디오 노벨이 있는 화는 카드에서 외부 링크 대신 이 리더 페이지로 이동

## 남은 세부 사항: 일단 기본값으로 진행

아래는 아직 사용자 확인을 받지 않은 항목이지만, 프로토타입을 진행하기 위해 다음 기본값으로 우선 구현합니다. 실제로 써보면서 마음에 안 들면 언제든 바꿉니다.

| 항목 | 기본값 |
|---|---|
| 구간 전환 | 이전 곡은 ~0.6초 페이드아웃, 새 곡은 페이드인 (뚝 끊기지 않게) |
| 뒤로 스크롤 시 | 이미 지나간 구간에 다시 들어오면 처음부터 다시 재생 (구간에 들어올 때마다 항상 같은 동작) |
| sound 경로 매핑 | `<sound="music/official/novel/fullmoon">` → `src/audioNovel/asset/sound/music/official/novel/fullmoon.mp3` (확장자는 `.mp3` 고정, 대소문자·폴더명은 실제 파일과 맞춰야 함) |
| 본문 줄바꿈 규칙 | **문단마다 `<sound>...</sound>`로 감싸는 것을 문단 구분으로 사용** (빈 줄 자체는 구분자로 쓰지 않음) |
| `Official.json` 연결 | 게시물 항목에 `reader` 필드가 있으면 카드 클릭 시 리더 페이지로 이동, 없으면 기존처럼 원문 새 탭 유지 |
