# 보안·성능 회귀 검증

`npm test`는 Node의 테스트 러너와 Web API, 메모리 R2/D1/DO 모형을 사용합니다.
원격 데이터나 Cloudflare 계정에 접근하지 않습니다.

검증 범위:

- 모든 HTML의 로컬 스크립트·스타일 참조와 브라우저 JSON·Worker import 경로
- UTF-8 바이트 기준 본문 제한과 스트림 취소
- 실제 계정·문학 게시글 검증 및 공유 경로를 통한 가입 제한 우회 차단
- 동시 가입 시 IP별 일일 5개 상한, 재시도 멱등성, 제한 저장소 장애 처리
- 접속자 API의 출처 검증, 클라이언트별 세션 격리·상한, 저장 횟수 제한
- 4,000개를 넘는 공개 북마크의 전체 조회, 인덱스 이어 만들기와 동시 갱신
- Markdown 속성 삽입 차단과 일반 숫자·인라인 코드 보존

`npm run build`는 별도로 실행합니다. 모의 테스트는 실제 Workers 런타임의
할당량, 네트워크 지연, R2 제한을 대신 검증하지 않습니다.

## 운영 동작

- 추가 시크릿·바인딩·D1 스키마 변경 없이 기존 리소스를 사용합니다.
- 신규 가입은 기존 인증 요청 제한과 R2 조건부 쓰기 예약을 사용합니다.
  기존 계정 조회는 일일 가입 한도를 소진하지 않습니다. 생성 실패 시에도
  예약은 보수적으로 유지하지만, 같은 개인 코드의 재시도는 재차 차감하지 않습니다.
  배포 당일의 기존 KV 가입 횟수도 최초 예약에 합산합니다.
- 접속자 수는 익명 탭 수의 근사치입니다. IP별 분당 요청 60회·새 세션 10개,
  활성 세션 20개 및 전체 활성 세션 1,000개 상한을 둡니다. 공유 IP가 많은
  환경에서는 일부 탭이 집계되지 않을 수 있습니다. 봇 여부를 판정하는 기능은 아닙니다.
  원본 IP는 저장하지 않고 일 단위 해시를 사용합니다. 상태 저장은 요청 중
  30초 간격으로 묶으며, 메모리 유실 시 최근 피크 일부는 소실될 수 있습니다.
- 공개 북마크는 R2 `indexes/library-v1.json`의 공개 메타데이터를 읽습니다.
  기존 1분 Cron이 최대 8개의 R2 목록 페이지를 읽고, 더 큰 목록은 다음 실행에
  이어서 처리합니다. 최초 인덱스가 완성되기 전에는 불완전한 검색 결과 대신
  503을 반환합니다. 소규모 목록은 첫 조회에서 즉시 생성됩니다.
  게시·수정·삭제 시 인덱스도 갱신하고, 갱신 실패는 Cron이 복구합니다.
- 모바일 로고의 기존 캐스케이드 보정과 모든 이미지 경로는 유지합니다.
